1️⃣  GO TO RAILWAY
    → Open: https://railway.app
    → Click "Login" → Sign in with GitHub
    → Authorize Railway

2️⃣  CREATE MYSQL DATABASE
    → Click "+ New"
    → Select "Database"
    → Choose "MySQL"
    → Click "Add MySQL"
    → ✅ Railway creates database automatically

3️⃣  DEPLOY YOUR BACKEND
    → Click "+ New" again
    → Select "GitHub Repo"
    → Find "SeaTara_Hotel_Management_app"
    → Click on it
    → Railway will auto-detect Dockerfile and start building

4️⃣  ADD ENVIRONMENT VARIABLES
    → Click on your deployed service
    → Go to "Variables" tab
    → Click "New Variable" and add:

    SPRING_PROFILES_ACTIVE
    railway

    JWT_SECRET
    lxp8L0y7eotsrZ2atleYIar4Cf/ojLBRsyg8o+39IGIlvQN2Gw1I/COoLcrTgdJaFWQcguC4Ug1YBIGl7G1B4g==

    (Railway automatically provides MySQL variables - no need to add them!)

5️⃣  GENERATE PUBLIC URL
    → Go to "Settings" tab
    → Scroll to "Networking" section
    → Click "Generate Domain"
    → You'll get: https://sitara-hotel-backend.up.railway.app

6️⃣  WAIT FOR DEPLOYMENT
    → Go to "Deployments" tab
    → Watch the build logs
    → Wait for "SUCCESS" status (2-3 minutes)
    → ✅ Your backend is LIVE!

Build Failed?
→ Check "Deployments" tab → Click failed deployment → View logs

App Crashes?
→ Check if MySQL service is running
→ Verify environment variables are set
→ Check logs for errors

Database Connection Failed?
→ MySQL takes 30 seconds to start
→ Make sure MySQL service is in same project
→ Railway auto-links them

Can't Access?
→ Make sure domain is generated in Settings → Networking
→ Check if deployment shows "SUCCESS"
